Tensor Space Specification

74-Dimensional Multi-Signal Feature Space.

MailGuard AI models heterogeneous email payloads into a compact 74-dimensional vector across three complementary forensic signal groups:

15D
Identity & Authentication

SPF, DKIM, DMARC validation states, sender identity consistency, domain alignment indicators, and RFC 2369 List-Unsubscribe header evidence.

30D
Routing & Topology

Hop counts, relay timing delta ($\Delta t_i$), inter-MTA latency vectors, routing irregularities, and infrastructure topology extracted from Received: headers.

29D
Content & Spectral Dynamics

Body length, vocabulary density, urgency tokens, combined with Fast Fourier Transform (FFT) harmonic spectral invariants from the raw character stream.

🔗 URL Spoofing & Homoglyphs

Detects Cyrillic vs Latin visual homoglyphs, concealed target hyperlinks where anchor text differs from actual destinations (href mismatch), open redirects, and newly registered high-risk TLDs.

⏰ Odd-Time Anomalies

Analyzes MIME Date headers against historical organizational circadian rhythms. Flags anomalous off-hour transmissions (e.g., 3:00 AM CEO wire transfer requests) combined with server timestamp discrepancies across relay hops.

🚨 Artificial Urgency Exploits

Quantifies cognitive coercion patterns designed to bypass human rational thinking (e.g., "Immediate action required", "Account suspended within 2 hours", "Final legal notice") using localized semantic intensity scoring.

🌐 Header & Routing Spoofing

Inspects the chain of custody in RFC 5322 Received: headers to spot forged envelope senders, MTA latency injection, and SPF/DKIM authentication failures disguised through custom relay proxies.

👁️‍🗨️ Zero-Width Steganography

Uncovers invisible zero-width spaces (U+200B, U+FEFF) and RTL override characters maliciously injected into body text or sender display names to break NLP keyword filters while remaining invisible to the human eye.

📎 Double-Extension Payload Trap

Flags deceptive file attachments leveraging whitespace padding or dual-extension masquerading (e.g., Invoice_Q3.pdf.vbs or Receipt.docx.exe), alongside mismatched MIME content-type headers.

Architecture Flow

How MailGuard AI operates.

A multi-tier pipeline engineered for Chrome Manifest V3, eliminating UI thread freezing while handling asynchronous Service Worker lifecycles.

1
Content Script Observer (content.js)

Monitors Gmail viewport mutations using lazy on-demand row detection, injecting non-intrusive threat indicators (flex-shrink: 0) without layout shifting.

2
Sandboxed Service Worker Neural Core (background.js)

Fetches RFC 5322 raw authentication headers (SPF, DKIM, DMARC), extracts the 74-dimensional vector, and executes dual-expert inference via the local V8 engine.

3
Explainable AI Dashboard (popup.js)

Translates complex mathematical tensors into human-readable risk diagnostics, displaying top attack contributors alongside one-click Trust Whitelist controls.

Mathematical Rigor

Scientific foundation.

The four core mathematical formulations powering real-time edge evaluation directly inside the browser V8 JavaScript engine.

Supervised Threat Scoring

1. Deep Neural Forward Pass (MLP)

Maps normalized 74-D input vector $\mathbf{x}$ to non-linear threat probability $p \in [0, 1]$ via a multi-tier feedforward perceptron. Hidden layers utilize ReLU non-linearities, terminating in an output Sigmoid activation $\sigma$.

$$\begin{aligned} \mathbf{h}_1 &= \text{ReLU}(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1) \\ \mathbf{h}_2 &= \text{ReLU}(\mathbf{W}_2\mathbf{h}_1 + \mathbf{b}_2) \\ p &= \sigma(\mathbf{W}_3\mathbf{h}_2 + \mathbf{b}_3) \end{aligned}$$
Hybrid Decision Fusion

2. Composite Threat Score Function

Computes a calibrated convex combination between supervised posterior probability $p$ and OCSVM boundary deviation $S_{\text{OCSVM}}$ using optimal fusion weighting $\alpha$, evaluated against decision boundary threshold $\tau$.

$$S_{\text{composite}} = \alpha p + (1 - \alpha) S_{\text{OCSVM}} \quad (\text{Threshold: } \tau)$$
Explainable AI Diagnostics

3. First-Order SHAP Attribution ($O(74)$)

Approximates Shapley marginal attributions $\phi_i(x)$ on-demand via deterministic sequential leave-one-out feature ablation, collapsing intractable exponential complexity $O(2^{74})$ into a lean $O(74)$ linear pass.

$$\phi_i(x) \approx f(x) - f(x_{\setminus \{i\}})$$
Adversarial Evasion Forensics

4. Discrete Fourier Spectral Analysis (FFT)

Detects non-semantic evasion techniques (e.g., zero-width unicode steganography and homoglyph substitution) by converting ASCII ordinal sequences $x[n]$ into frequency domain harmonic spectrum $X[k]$.

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j \frac{2\pi}{N} k n}$$
